> 作者身份：个人 Python 开发者，无公司、无团队、无投资
> 产品现状：MVP v0.2 已上线（FastAPI + H5）
> 线上地址：https://shiling-5sdl.onrender.com
> 日期：2026年8月

---

```
✅ 已完成
```

## 二、接下来该做什么（按优先级排序）

### 第一阶段：获取种子用户（第1-4周）

**目标：100个真实用户，验证需求**

#### 1. 产品打磨（1周）

| 待做 | 说明 | 难度 |
|------|------|------|
| 加载速度优化 | Render 免费版冷启动慢，加 loading 动画 | ⭐ |
| 分享功能 | 生成菜品卡片图片，方便发朋友圈 | ⭐⭐ |
| 专题页面 | 快手菜/减脂餐/宴请菜等标签分类 | ⭐ |
| SEO 基础 | title/description/og 标签 | ⭐ |
| 百度统计接入 | 持久化数据，看用户行为 | ⭐ |

#### 2. 推广获客（第2-4周）

**免费渠道，零成本：**

| 渠道 | 具体操作 | 预期效果 |
|------|---------|---------|
| **小红书** | 发"今天吃什么"系列图文，每篇带链接 | 高，美食类流量大 |
| **抖音** | 录 15s 演示视频："选不到菜？1秒帮你决定" | 高，短视频传播快 |
| **微信群** | 发到家族群/朋友群/同事群，让大家试用 | 中，种子用户来源 |
| **知乎** | 回答"每天不知道吃什么"类问题，附链接 | 中，长尾流量 |
| **V2EX/掘金** | 发技术贴讲你怎么做的，附在线体验 | 中，开发者圈子 |
| **豆瓣** | 美食小组发帖 | 低-中 |

**内容模板：**

```
标题：做了一个「今天吃什么」的网站，根据你的城市和口味推荐菜

正文：
每天最难的问题不是工作，是"今天吃什么"
做了一个小工具，选好你在哪个城市、口味偏好
自动推荐当季适合的菜，还有详细做法

200道菜，覆盖全国22个省的特色菜系
24节气时令推荐，吃得应季

在线体验：https://shiling-5sdl.onrender.com
免费的，不用注册

大家觉得还缺什么功能？评论区告诉我
```

#### 3. 收集反馈

- 在页面底部加一个反馈入口（微信号或问卷链接）
- 记录用户最常搜什么、最常看什么菜
- 每周看一次统计数据：`/api/stats?key=shiling2026`

### 第二阶段：产品升级（第5-8周）

**前提：已有 100+ 活跃用户，确认需求真实**

#### 1. 注册个体户（1-2周）

| 步骤 | 说明 | 费用 |
|------|------|------|
| 起名 | XX科技工作室 / XX信息服务部 | 免费 |
| 办理 | 当地市场监管局或线上（浙里办/粤商通等） | 免费 |
| 经营范围 | 信息技术服务、软件开发、互联网信息服务 | - |
| 对公账户 | 可选，部分银行免费 | 0-100元 |
| 时间 | 1-3个工作日 | - |

#### 2. 小程序上线

| 步骤 | 说明 |
|------|------|
| 注册微信小程序企业号 | 需要营业执照，300元认证费 |
| 备案域名 | 买一个 .com 域名（约 50元/年） |
| ICP 备案 | 免费，但需要 1-2 周 |
| 云服务器 | 腾讯云/阿里云轻量 2C2G 约 50元/月 |
| 小程序开发 | 用 uni-app 或 Taro 把 H5 包一层 |

**预算合计：约 500-800 元**

#### 3. 功能升级

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 用户登录（微信授权） | P0 | 有了小程序就能做 |
| 一周食谱计划 | P0 | 用户粘性核心功能 |
| 做菜打卡日历 | P1 | 增加使用频率 |
| 专题集合（快手菜/减脂餐） | P1 | 内容运营 |
| 食材搜索优化 | P2 | "冰箱有什么做什么" |

### 第三阶段：商业化探索（第3-6个月）

**前提：1000+ 用户，周活跃 > 30%**

#### 盈利模式

```
免费模式（大部分用户）
├── 每日推荐 5 道菜
├── 基础搜索
├── 收藏 / 历史
└── 时令日历

付费模式（Pro 会员 9.9元/月）
├── 无限推荐
├── AI 智能搭配（根据冰箱食材）
├── 营养分析报告
├── 一周食谱自动规划
└── 无广告
```

#### 其他收入

| 方式 | 说明 | 难度 |
|------|------|------|
| 小程序流量主广告 | 用户 > 1000 可开通 | ⭐ |
| 食材电商分佣 | 接入美团买菜/盒马 CPS 链接 | ⭐⭐ |
| 品牌合作 | 调味品/厨具品牌推荐位 | ⭐⭐⭐ |

### 第四阶段：寻找合伙人/融资（6个月+）

**前提：5000+ 用户，有收入，增长趋势明显**

#### 找合伙人

你需要的人：
- **运营合伙人**：负责内容和推广（最缺）
- **设计师**：兼职即可，美化 UI

去哪找：
- 即刻 App 发帖找合伙人
- 独立开发者社区（IndieHacker中国、V2EX）
- 大学创业社团

#### 融资（如果需要）

| 阶段 | 金额 | 来源 |
|------|------|------|
| 天使轮 | 10-50万 | 个人投资人、创业比赛奖金 |
| 种子轮 | 50-200万 | 早期 VC（真格基金、梅花创投等） |

**融资准备材料：**
- BP（商业计划书）：10页 PPT
- 核心数据：用户数、留存率、增长曲线
- Demo：线上可体验的产品

## 五、避坑指南

| ❌ 不要做 | ✅ 应该做 |
|----------|----------|
| 一开始就搞小程序 | 先用 H5 验证需求 |
| 花钱买服务器 | 用免费平台到有用户为止 |
| 做社区/电商 | 先做好推荐这一个核心功能 |
| 自己闷头开发 | 发出去让别人用，听反馈 |
| 追求完美再上线 | 能用就发，快速迭代 |
| 找投资人 | 先找 100 个用户 |

## 六、关键指标（North Star Metric）

**核心指标：周活跃用户数（WAU）**

| 里程碑 | WAU | 该做什么 |
|--------|-----|---------|
| 冷启动 | 0→50 | 朋友圈+社群推广 |
| 种子验证 | 50→200 | 确认需求，优化体验 |
| 增长期 | 200→1000 | 注册个体户，上小程序 |
| 商业化 | 1000→5000 | 开通广告/会员 |
| 融资期 | 5000+ | 准备 BP，找投资 |

---

> **记住：你现在最重要的事不是加功能，是让 100 个人用起来。**
> 
> 产品已经上线了，现在该出去推广了。
