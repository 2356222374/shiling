# 「食令」个人 Python 开发者落地实操指南

> 没有公司、没有营业执照、没有团队、没有投资，只有 Python 技能和一个想法——怎么办？

---

## 第零步：先想清楚一个问题

**你现在不需要投资，也不需要营业执照。**

很多人的误区是：想法 → 注册公司 → 拉投资 → 招团队 → 开发产品。这条路 99% 的人走不通。

正确的路径是：

```
想法 → 最小验证(花0元) → 有用户了 → 注册公司 → 有数据了 → 拉投资
```

先证明「有人需要」，再考虑钱和公司的事。下面是具体怎么做。

---

## 一、分阶段落地路径（个人开发者版）

### 阶段零：验证需求（第1-2周，花费 0 元）

**目标：** 确认真的有人需要这个东西，不要自嗨

#### 做什么

1. **建一个微信群「今天吃什么」**
   - 在朋友圈、小红书、抖音评论区发：「每天不知道吃什么的扣 1」
   - 拉 100-200 个人进群
   - 每天手动在群里发一条「今日推荐」（基于城市+季节手动挑 3 道菜）
   - 观察：有没有人回复？有没有人说「这个好，正愁吃什么」？

2. **去餐饮老板群/美食城蹲几天**
   - 找 5-10 个餐饮小老板聊天
   - 问：「你平时怎么决定菜单的？换季的时候怎么调？食材从哪进的？」
   - 记录他们的真实痛点，而不是你想象的痛点

3. **做一个问卷**
   - 腾讯问卷（免费），20 道题
   - 核心问题：你每天花多少时间想吃什么？你愿意为「智能推荐今天吃什么」付费吗？
   - 发到微信群、朋友圈、知乎、小红书
   - 目标：收集 200+ 份有效问卷

#### 验证标准

- 微信群里 > 30% 的人每天互动 → 需求存在
- 5 个餐饮老板中 > 3 个说「有这样的工具我愿意试」→ B 端有需求
- 问卷中 > 50% 的人表示「经常不知道吃什么」→ C 端有需求

**如果验证失败 → 停下来，换个方向，省下几个月的时间。**
**如果验证通过 → 进入下一步。**

### 阶段一：做 MVP（第3-8周，花费 < 500 元）

**目标：** 用你的 Python 技能，花最少的钱做一个能用的东西

#### 技术方案（纯 Python 个人开发者版）

**不要一上来就做小程序。先做一个微信公众号 + H5 页面。**

为什么？
- 微信公众号不需要营业执照（个人号就行）
- H5 页面不需要审核
- Python 全栈你一个人就能搞定
- 验证完再考虑小程序

```
MVP 技术栈（你一个人就能搞定）：

前端：HTML + CSS + JavaScript（简单 H5 页面）
     或 Streamlit / Gradio（Python 直接出 Web UI）
后端：FastAPI（你熟悉的 Python）
数据库：SQLite（起步）→ PostgreSQL（用户多了再切）
部署：腾讯云 / 阿里云轻量服务器 99元/年
域名：可选，先用 IP 或免费域名
```

#### MVP 功能（砍到极致，只做这些）

```
MVP v0.1 — 只做一个功能：「今天吃什么」

用户打开 H5 页面：
  1. 选择城市（下拉框）
  2. 选择口味偏好（辣/不辣/清淡）
  3. 点击「推荐」
  4. 显示 3 道推荐菜品（菜名+图片+简单做法+当季食材）

就这么简单。其他功能全部砍掉。
```

#### 你要写的代码

```python
# 项目结构（就这么几个文件）

shiling-mvp/
├── main.py              # FastAPI 入口
├── recommend.py         # 推荐逻辑
├── data/
│   ├── dishes.json      # 菜品数据（先手动整理 200 道）
│   └── seasons.json     # 时令对照表
├── templates/
│   └── index.html       # 前端页面
├── static/
│   └── style.css
└── requirements.txt
```

#### 菜品数据怎么来？

**不需要自己从零采集，这些免费数据源够 MVP 用：**

| 来源 | 数据量 | 获取方式 | 合法性 |
|------|--------|----------|--------|
| 中华菜谱网/美食天下 | 10万+ | 爬虫（仅个人学习使用） | 注意robots.txt |
| 豆果美食开放数据 | 5万+ | API/爬虫 | 需遵守协议 |
| 《中国菜谱大全》等书籍 | 5000+ | 手动整理 | 公共知识 |
| ChatGPT / Claude 生成 | 无限 | 提示词生成 | 需人工审核 |
| 自己 + 朋友整理 | 200+ | 人工 | 完全合法 |

**MVP 阶段建议：** 用 AI 批量生成 200 道菜的基础数据（菜名+菜系+食材+做法+适合季节），然后人工审核修正。这个用 Python 脚本 + AI API 一天就能搞定。

#### 花费明细

| 项目 | 费用 | 说明 |
|------|------|------|
| 云服务器 | 99元/年 | 腾讯云/阿里云学生机或轻量服务器 |
| 域名 | 0-55元/年 | .cn域名首年约10元，或用免费域名 |
| AI API 调用 | 约50元 | 生成菜品数据 |
| 微信公众号 | 0元 | 个人号免费 |
| **合计** | **< 200元** | |

### 阶段三：该注册公司了（约第4个月）

**当你有了 1000+ 用户和验证数据后，再注册公司。不是更早。**

#### 注册什么类型的公司？

| 类型 | 适合阶段 | 费用 | 优缺点 |
|------|----------|------|--------|
| **个体工商户** | 刚验证完 | 0-500元 | 最简单，能开票收款，但无法融资 |
| **有限责任公司** | 准备融资 | 500-2000元 | 可以融资、有限责任保护，推荐 |
| **合伙企业** | 有合伙人 | 500-1500元 | 灵活，但无限责任 |

**推荐：先注册个体工商户（做小程序需要），验证跑通后再注册有限公司。**

#### 注册流程（2026年极简版）

```
1. 公司名预核准
   - 登录「国家企业信用信息公示系统」核名
   - 推荐名称格式：XX市食令科技有限公司

2. 准备材料
   - 身份证原件
   - 注册地址（可用虚拟地址，200-500元/年）
   - 公司章程（模板网上下载）

3. 办理登记
   - 线上：当地市场监管局官网/小程序，全程网办
   - 线下：去当地政务大厅，当天可拿执照

4. 后续事项
   - 刻章（公章+财务章+法人章）：约200-500元
   - 开银行对公账户：免费-500元
   - 税务登记：网上办理，免费
   - 社保账户：有员工再开

总费用：1000-3000元（含虚拟地址）
总时间：3-7个工作日
```

#### 拿到营业执照后能做什么

| 事项 | 需要执照？ | 说明 |
|------|-----------|------|
| 发布微信小程序 | ✅ 需要 | 企业主体才能发布 |
| 开通微信支付（商户） | ✅ 需要 | 收款必须 |
| 注册商标「食令」 | ✅ 需要 | 建议尽早注册 |
| 申请软件著作权 | ✅ 需要 | 融资加分项 |
| 入驻各应用市场 | ✅ 需要 | 发布 App |
| 签订商业合同 | ✅ 需要 | 与供应商签约 |
| 融资 | ✅ 需要有限公司 | 投资人投的是公司股权 |

**有了公司 + 用户数据后，把 H5 升级为微信小程序，同时准备融资材料。**


## 二、要不要融资？怎么融？

### 2.1 先回答：你现在需要融资吗？

**大概率不需要。** 理由：

| 阶段 | 需要融资吗？ | 为什么 |
|------|-------------|--------|
| 验证需求 | ❌ 不需要 | 0元成本，微信群+问卷就行 |
| 做 MVP | ❌ 不需要 | < 500元，一个人就能做 |
| 获取首批用户 | ❌ 不需要 | 免费渠道（小红书/抖音/社群） |
| 注册公司 | ❌ 不需要 | < 3000元 |
| 小程序上线 | ⚠️ 看情况 | 如果自学前端就不需要，外包约1万 |
| 全职投入+招人 | ✅ 可能需要 | 如果你还在上班想辞职全职做这个 |
| 大规模推广 | ✅ 需要 | 付费投放、地推等烧钱 |

### 2.2 什么时候去融资？

**带着这些东西去找投资人，成功率从 1% 提升到 10-20%：**

| 你需要有的 | 说明 | 怎么得到 |
|-----------|------|----------|
| 一个能用的产品 | 不是 PPT，是真的能打开用的 | 你自己开发的 MVP |
| 真实用户数据 | 注册数、日活、留存率、用户反馈 | 阶段二获取 |
| 收入或收入模型验证 | 哪怕月收入只有 100 块 | C端会员/打赏/小额广告 |
| 清晰的商业逻辑 | 怎么赚钱，市场多大 | 你已经有BP了 |
| 你自己的执行力证明 | 一个人做出了产品并获得了用户 | 最打动投资人的东西 |

**一句话：投资人不投想法，投的是「已经做出来了 + 已经有人用了 + 团队执行力强」。**

### 2.3 融资渠道（按适合程度排序）

#### 渠道一：身边的人（最容易，最推荐先尝试）

```
谁：
- 家人、亲戚
- 同学、朋友
- 前同事、前领导

怎么说：
  「我做了一个帮人解决每天吃什么的工具，已经有 1000 多人在用，
   现在想辞职全职做这个，需要 10-20 万启动资金，
   你愿意投一点吗？我给你 X% 的股份。」

金额：5-30万
优势：信任成本低、流程简单
风险：不要借太多，影响关系

⚠️ 重要：即使是朋友投资，也要签正式的投资协议！
```

#### 渠道二：政府创业扶持（免费的钱）

```
各地都有创业扶持政策，很多人不知道：

- 创业补贴：各地 5000-20000 元不等（深圳最高 45 万）
- 创业担保贷款：最高 30 万，政府贴息
- 创业孵化器：免费办公场地 + 导师 + 资源对接
- 创业大赛奖金：参加各种创业比赛，获奖有奖金

怎么找：
1. 搜索「你所在城市 + 创业补贴」
2. 去当地人社局官网查
3. 关注当地创业孵化器（每个城市都有）
4. 微信搜索「XX市创业服务」公众号
```

**具体可以申请的：**

| 项目 | 金额 | 条件 | 怎么申请 |
|------|------|------|----------|
| 一次性创业补贴 | 5000-15000元 | 首次创业，有营业执照 | 当地人社局 |
| 创业场地补贴 | 500-1000元/月 | 入驻孵化器 | 孵化器申请 |
| 创业担保贷款 | 最高30万 | 有营业执照，无不良征信 | 银行+人社局 |
| 创新创业大赛 | 5000-100000元 | 有项目，参加比赛 | 各比赛官网报名 |
| 大学生创业补贴 | 各地不同 | 毕业5年内 | 人社局 |

## 三、个人开发者的现实行动清单

### 本周就能做的事（排好优先级）

| 优先级 | 事项 | 时间 | 花费 |

## 四、避坑指南（个人开发者最容易犯的错）

### ❌ 坑一：一上来就做很大

```
错误：花3个月把完整的C端+B端+S端全做出来
正确：花2周做一个「今天吃什么」H5页面，先看有没有人用
```

### ❌ 坑二：先注册公司再做产品

```
错误：先花钱注册公司、租办公室、找合伙人
正确：先做产品验证，有用户有数据了再注册公司
```

### ❌ 坑三：觉得「我的想法很值钱，不能告诉别人」

```
错误：保密，不跟任何人说，怕被抄
正确：想法不值钱，执行力才值钱。大胆告诉所有人，
     收集反馈，别人不会抄你的（真的不会）
```

### ❌ 坑四：一个人硬扛所有事

```
错误：自己做产品+设计+运营+推广+客服+财务
正确：
  - 设计：用 Canva 等免费工具，不需要设计师
  - 前端：MVP 阶段用 Streamlit/H5 凑合，后期外包
  - 运营：自己先做，是最了解用户的方式
  - 找一个互补的合伙人（比如运营型的朋友）
```

### ❌ 坑五：把融资当目标

```
错误：觉得「拿到融资就成功了」
正确：融资是手段不是目的。很多好产品从来没融过资，
     靠自己的收入活得很好（独立开发者模式）
```

## 五、两条路你可以选

### 路线 A：独立开发者路线（不融资）

```
目标：做一个能养活自己的产品
收入来源：C端会员(9.9元/月) + 食材电商佣金
预期时间线：
  - 6个月：上线+1000用户
  - 12个月：5000用户，月收入3000-5000元
  - 24个月：2万用户，月收入1-3万元（可辞职全职做）
优点：自由、不用对投资人负责、100%控制权
缺点：增长慢、规模有限
```

### 路线 B：创业融资路线

```
目标：做一个大平台，C-B-S三端联动
融资路径：
  - 0-6个月：自费做MVP + 验证（花费<5000元）
  - 6-9个月：注册公司，申请创业补贴，找天使投资
  - 9-18个月：天使轮100-300万，招2-3个人
  - 18-30个月：Pre-A轮1000万，扩大团队
优点：增长快、有可能做大
缺点：压力大、稀释股份、可能失败
```

**建议：先走路线 A 做到有用户有收入，再决定要不要走路线 B。这两条路不冲突。**

## 六、常见问题

### Q：我还在上班，可以用业余时间做吗？

**可以，而且建议你先保持工作。** MVP 阶段每天投入 2-3 小时足够。等有了用户和收入基础后再考虑辞职。

### Q：我不会前端怎么办？

**Python 也能做前端：**
- Streamlit：Python 直接写 Web 应用，零前端基础
- Gradio：同上，更适合 AI 应用展示
- FastAPI + Jinja2 模板：简单 HTML 渲染

MVP 阶段用这些完全够了。后面再找前端外包或自学。

### Q：需要注册商标吗？

注册一个 45 类（餐饮）的「食令」商标，费用约 300 元。建议在注册公司的时候顺便做。如果被占了就换个名字，不影响产品本身。

### Q：一个人做技术会不会太慢？

你一个 Python 开发者做 MVP 完全够了：
- 后端 FastAPI ：你的主场
- 数据处理/爬虫：Python 强项
- 推荐算法：scikit-learn 几十行就能写
- 部署运维：Docker + 云服务器

**唯一短板是前端，但 MVP 阶段用 Streamlit 或简单 H5 足矣。**
